# Реестр питомцев

Лабораторная работа № 3 по теории алгоритмов, вариант 12. Приложение помогает вести карточки домашних животных и отслеживать изменения в реестре.

## Запуск приложения на PySide6

Требуется Python 3.11 или новее. В папке проекта выполните:

```powershell
python -m pip install -r requirements.txt
python desktop.py
```

## Этап 1. Ядро и SQLite

Ядро хранит карточки в SQLite и проверяет данные перед сохранением. Кличка, вид и владелец обязательны, породу и дату рождения можно пропустить. Добавление, изменение или удаление карточки сохраняется в журнале в той же транзакции.

## Этап 2. Интерфейс на PySide6

### Краткая справка

Заполните форму на вкладке «Питомцы» и нажмите «Добавить питомца». Для изменения или удаления выберите нужную строку в таблице. На вкладке «Активность» доступны журнал и график операций за последние семь дней. Кнопка «Справка» в правом верхнем углу доступна с обеих вкладок.

## Этап 3. Веб-версия на FastAPI

Веб-версия позволяет добавлять, изменять и удалять карточки, а также смотреть журнал и график активности. При запуске командой ниже FastAPI по умолчанию слушает порт `8000` и использует тот же файл `pets.sqlite3`, что и PySide6 в режиме SQLite. Данные SQLite хранятся отдельно от данных PostgreSQL в Docker. Установите зависимости из `requirements.txt`, выполните команду из папки проекта и откройте [реестр на порту 8000](http://127.0.0.1:8000/).

```powershell
python -m uvicorn web_app.main:app
```

## Этап 4. Режим PostgreSQL в Docker

При первом запуске скопируйте `.env.example` в `.env` и задайте пароль PostgreSQL в одинарных кавычках. Запустите Docker Desktop, выполните команду из папки проекта и откройте [реестр на порту 8080](http://127.0.0.1:8080/).

```powershell
docker compose up --build --wait
```

Docker перенаправляет порт `8080` компьютера на порт `8000` веб-контейнера, а PySide6 подключается к той же базе PostgreSQL через `127.0.0.1:55432`.

### Подключение PySide6 к PostgreSQL

```powershell
$env:PET_REGISTRY_DB_HOST = '127.0.0.1'
python desktop.py
Remove-Item Env:PET_REGISTRY_DB_HOST
```

### Запуск и остановка в Docker Desktop

После первой сборки управляйте контейнерами через **Containers → lab03 → Start / Stop**. Карточки и журнал хранятся в томе PostgreSQL, а правки из другого интерфейса видны после обновления страницы или команды «Файл → Обновить» в PySide6.
