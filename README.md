# Реестр питомцев

Лабораторная работа № 3 по теории алгоритмов, вариант 12. Приложение помогает вести карточки домашних животных и отслеживать изменения в реестре.

## Запуск приложения на PySide6

Требуется Python 3.11 или новее. В папке проекта выполните:

```powershell
python -m pip install -r requirements.txt
python desktop.py
```

## Этап 1. Ядро и SQLite

Ядро хранит карточки в SQLite и проверяет данные перед сохранением. Кличка, вид и владелец обязательны, породу и дату рождения можно пропустить. Добавление, изменение или удаление карточки сохраняется в журнале в той же транзакции.

## Этап 2. Интерфейс на PySide6

### Краткая справка

Заполните форму на вкладке «Питомцы» и нажмите «Добавить питомца». Для изменения или удаления выберите нужную строку в таблице. На вкладке «Активность» доступны журнал и график операций за последние семь дней. Кнопка «Справка» в правом верхнем углу доступна с обеих вкладок.

## Этап 3. Веб-версия на FastAPI

Веб-версия позволяет добавлять, изменять и удалять карточки, а также смотреть журнал и график активности в браузере. Данные хранятся в отдельном файле `pets-web.sqlite3`. После установки зависимостей из `requirements.txt` запустите сервер из папки проекта и откройте [реестр](http://127.0.0.1:8000/).

```powershell
python -m uvicorn web_app.main:app
```
